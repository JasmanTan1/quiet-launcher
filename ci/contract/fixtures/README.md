# Contract fixtures

All identifiers, credentials, display names and example origins here are synthetic.
Tokens beginning `fixture_` have no authority. They must never become application
defaults. The `.example` URLs are inert examples, not services to contact.

`snapshot.json`, `playlist.json`, `guest-state.json` and `party-qr.json` supply
baseline API bodies. `schema-cases.json` contains accepted and rejected shapes;
validate them using the named OpenAPI component, including local references.
`http-cases.json` gives body/query/header and status examples. A mock harness
injects a synthetic authenticated host/device/party/guest principal appropriate
to each operation, or the denied principal named by an error case. These are
examples for a harness, not commands to send to a server. Oversize upload is a
generated byte-count instruction, not an included large file.

`transition-cases.json` defines deterministic input/expected-output vectors for
both clients and the coordinator. Timer offsets are milliseconds from expiry;
the schedule vector asserts chimes at 1,200/3,600 ms, restore at 5,600 ms and
completion at 8,100 ms without stopping playback. Deadline `elapsedMs` includes
network/render delay from request start, measured on a monotonic clock.
The localMonotonic value is an origin and does not change a relative deadline.

`launcher.json` gives two generic profiles, one installed mock app and one missing
mock app. Screenshot fixtures may start with this populated state; actual first
run starts with an empty profile. Installed app labels/icons come from mocks,
never from an existing device catalog.

`tone.wav` is a generated 250 ms mono tone. Mock track descriptions last 120
seconds: repeat generated samples or supply a mock clock when testing track
transitions. `geometric.png` is a generated 2×2 RGB image containing no metadata.
`media.json` records their sizes, hashes and generation provenance. Generate
separate oversized/malformed/animated inputs in isolated tests without downloads.

`verification-matrix.json` lists required implementation and release checks, all
pending until downstream workers run them. Passing schema or vector validation
does not mean an application implemented the behavior. Use injected mock
transport, an explicit isolated browser configuration if needed, denied external
network and a fake clock. Never run a media service or make provider requests.
