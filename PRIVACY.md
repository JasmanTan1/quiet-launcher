# Privacy

Quiet Launcher works offline and requests no Android permissions. It queries
activities advertising TV or standard launcher categories, displays their labels,
and opens only applications selected by the user or system Settings.

The active profile and its selected package IDs and labels are stored in local
app preferences. Profiles are local lists, not accounts or access controls. The
two profiles share the same installed applications and Android user. App backup
is disabled. Clear the app's storage or uninstall it to remove selections.

There is no analytics, remote configuration, web shortcut, account, automatic
update or media download feature. Opening another app hands control to that app;
its own privacy practices apply.
